cmfqsar API reference
=====================

This site is built from the docstrings of the source. It lists every public module, class,
method and function of the package with its signature, and the references inside the docstrings
are links. The same content, as one Markdown file, is ``docs/api.md`` in the repository. What the
modules are for, and worked scripts, are in the user manual (``docs/manual.md``, chapter *Using it
as a library*).
